# Start here — folders only

1. Confirm this is the correct Wayhunter GitHub repository clone.
2. Inspect existing files. **Do not overwrite** a working project or existing branch.
3. Read `AGENTS.md`, `docs/second-brain/ACTIVE_RULES.md`, and `docs/OWNERSHIP_MAP.md`.
4. Framework source/project files are **not** created by this pack. Use the official SDK/CLI to scaffold a working app separately, after checking for conflicts.
5. A `.gitkeep` file is only a tracked empty-folder placeholder; it is not functionality.
6. No commit / push now. Tomorrow review scaffold, test it, and separately submit PRs if the team agrees.

Note: for Angular, use the official Angular CLI to initialize the application **before copying folder skeletons into the repo**; `ng new` into a directory pre-filled with files can fail or conflict. Flutter/Backend also benefit from framework scaffolding first.
